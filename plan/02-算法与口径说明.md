## 一、步骤归一化（模块①）

### 1.1 步骤切分

**输入**：模型输出（含 `\u003c\u0069\u006d\u0065\u003e` 思维链）或 LaTeX/纯文本解答

**切分策略（确定性，零模型）**：

1. **思维链标签提取**：正则 `r'\u003c\u0069\u006d\u0065\u003e(.*?)\u003c/\u0069\u006d\u0065\u003e'`（非贪婪匹配），提取 `\u003c\u0069\u006d\u0065\u003e` 段作为主审计文本；`\u003c\u0069\u006d\u0065\u003e` 段外的内容作为"非思维链辅助"，标记 `reasoning_outside`。
2. **步骤边界检测**：按以下确定性规则切分（优先级从高到低）：
   - 显式编号：`^\s*(\d+)[.、)）]\s+`（行首编号）
   - 隐式分隔：空行 + 新段落
   - 公式块：`\$\$.*?\$\$` 或 `\\begin\{.*?\}.*?\\end\{.*?\}`
3. **每步产出**：`{step_no, raw_text, source_line_start, source_line_end, reasoning_tag}`

**确定性纪律**：
- 不可符号化的步骤一律标 `unsymbolizable`，不得虚高为 ok
- 切分覆盖率必须如实报告：分母 = 检出步骤数，分子 = 成功归一化数
- 非 UTF-8 编码一律报错（不猜测）

### 1.2 表达式归一化

**归一化目标**：将自然语言/LaTeX 数学表达式转为 SymPy 可计算的符号表达式。

**归一化管线**：

```
raw_text → LaTeX 提取 → 符号替换 → SymPy sympify → 归一化形式
```

1. **LaTeX 提取**：`\$\$(.*?)\$\$`、`\$(.*?)\$`、`\\begin\{equation\}(.*?)\\end\{equation\}`
2. **符号替换表**（确定性映射）：
   - `\alpha` → `a`、`\beta` → `b`、`\sum` → `Sum`、`\int` → `Integral`
   - `\times` → `*`、`\cdot` → `*`、`\div` → `/`
   - `\frac{a}{b}` → `(a)/(b)`、`\sqrt{x}` → `sqrt(x)`
3. **SymPy sympify**：`sympify(expr, evaluate=False)`（不自动求值，保留原始结构）
4. **归一化形式**：`simplify(expr)` 作为"标准形式"，原始形式保留为 `raw_expr`

**归一化失败处理**：
- 返回 `(None, "unsymbolizable", reason)`
- reason 枚举：`unparseable_latex` / `unknown_symbol` / `unsupported_construct` / `sympify_error`

### 1.3 覆盖率报告

```
总步骤数: N
成功归一化: M
不可符号化: N - M
覆盖率: M/N
不可符号化原因分布: {unparseable_latex: x, unknown_symbol: y, ...}
```

## 二、符号等价性判定（模块②）

### 2.1 三级语义

| Verdict | 含义 | 判定条件 |
|---|---|---|
| `ok` | 验证通过 | 相邻步表达式等价（sympy.simplify 差为 0） |
| `invalid` | 确证错误 | 相邻步表达式不等，且可构造最小反例 |
| `unverifiable` | 引擎能力外 | 表达式含不可判定构造（如归纳法、极限、不等式方向） |

### 2.2 等价性判定算法

```python
def verify_step(prev_expr, curr_expr, step_info):
    """
    验证相邻步骤的等价性。
    返回: Verdict(ok/invalid/unverifiable, evidence, counterexample)
    """
    # 1. 检查是否可符号化
    if prev_expr is None or curr_expr is None:
        return Verdict("unverifiable", "不可符号化步骤", None)

    # 2. 尝试符号等价性
    diff = simplify(curr_expr - prev_expr)
    if diff == 0:
        return Verdict("ok", "符号等价", None)

    # 3. 尝试数值反例（最小反例）
    # 对表达式中的自由变量，代入小整数测试
    free_vars = list(free_symbols(prev_expr | curr_expr))
    if free_vars:
        for values in generate_small_integer_tuples(free_vars, range(-3, 4)):
            try:
                prev_val = prev_expr.subs(values).evalf()
                curr_val = curr_expr.subs(values).evalf()
                if abs(prev_val - curr_val) > 1e-9:
                    return Verdict("invalid", "数值反例", dict(zip(free_vars, values)))
            except (TypeError, ZeroDivisionError):
                continue

    # 4. 无法判定
    return Verdict("unverifiable", "符号与数值均无法判定", None)
```

### 2.3 最小反例构造

- 自由变量取 `{-3, -2, -1, 0, 1, 2, 3}` 的笛卡尔积
- 优先返回使差值最大的反例
- 含除法时跳过使分母为 0 的赋值

### 2.4 不可判定构造登记

| 构造类型 | 处理方式 | 登记 |
|---|---|---|
| 归纳法（数学归纳） | unverifiable | `induction` |
| 极限（lim） | unverifiable | `limit` |
| 不等式方向 | unverifiable | `inequality_direction` |
| 含参不等式 | unverifiable | `parametric_inequality` |
| 复数域 | unverifiable | `complex_domain` |

## 三、首错锚定算法（模块③）

### 3.1 算法

```python
def locate_first_error(verdicts: list[Verdict]) -> FirstErrorResult:
    """
    输入: 每步的 verdict 列表
    输出: 首错锚 + 受污染步骤 + 独立失效步骤
    """
    first_error_idx = None
    contaminated = set()
    independent_failures = []

    for i, v in enumerate(verdicts):
        if v.status == "invalid":
            if first_error_idx is None:
                first_error_idx = i  # 最小序号为首错
            else:
                # 后续 invalid 步：判断是独立失效还是受污染
                if is_independent_failure(i, first_error_idx, verdicts):
                    independent_failures.append(i)
                else:
                    contaminated.add(i)

    return FirstErrorResult(
        first_error=first_error_idx,
        contaminated=sorted(contaminated),
        independent_failures=independent_failures,
        explanation=generate_explanation(first_error_idx, contaminated, independent_failures)
    )
```

### 3.2 受污染判定

- 若第 j 步的表达式直接依赖第 i 步的结果（变量名相同、表达式结构继承），则 j 受 i 污染
- 判定依据：表达式中是否出现首错步的"输出变量"

### 3.3 确定性纪律

- 首错锚定必须唯一且可解释
- 多步同时 invalid 时，报告最小序号为首错
- 不得只报"有错误"而不给位置

## 四、独立重算路径（模块④）

### 4.1 与符号路径的独立性

| 维度 | 符号路径 | 独立重算路径 |
|---|---|---|
| 引擎 | SymPy | 纯 Python 数值计算 |
| 表示 | 符号表达式 | 浮点/有理数 |
| 判定 | 等价性 | 数值一致性 |
| 精度 | 精确 | 容差 1e-9 |

### 4.2 独立重算算法

```python
def independent_recalc(final_assertion, normalized_steps):
    """
    独立数值重算，与符号路径实现独立。
    返回: 一致 / 不一致 / 无法独立重算
    """
    # 1. 从归一化步骤中提取最终断言
    target = final_assertion  # 如 "x = 5"

    # 2. 从第一步开始，用纯数值计算重算
    computed = None
    for step in normalized_steps:
        if step.status == "unsymbolizable":
            return "无法独立重算"
        computed = numeric_evaluate(step.expr)

    # 3. 与最终断言比对
    target_value = parse_assertion_value(target)
    if abs(computed - target_value) < 1e-9:
        return "一致"
    else:
        return "不一致"
```

### 4.3 容差与数值口径

**唯一定义点（K8）**：本节 `1e-9` 容差为全项目唯一数值口径。

- 所有数值比较走此容差
- 注记文本与算法同源（`TOLERANCE = 1e-9` 常量）
- 数值类断言一律走独立重算，不采信符号路径的自证

### 6.1 开关设计

```python
# src/hws_math_auditor/config.py
class Config:
    model_enabled: bool = False  # 默认关
    model_endpoint: str = ""     # 用户自备端点
    model_provider: str = "openai_compat"  # openai_compat | llama_cpp | omni_infer

```

### 6.2 模型仅用于解析兜底

- 当步骤切分/归一化失败时，若 `model_enabled=True`，才调用模型
- 模型输出仅用于"解析兜底"，不参与任何判定
- 判定结论永远来自确定性规则

### 6.3 快照机制

- 预置模型输出快照含：模型名、版本、生成参数、原始输出、sha256
- 快照随仓只存快照与真值台账，不分发模型权重
- 离线复跑用快照，不依赖当场跑模型
