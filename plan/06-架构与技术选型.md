## 三、技术选型

| 组件 | 选型 | 版本约束 | 理由 |
|---|---|---|---|
| 语言 | Python | ≥3.8 | 题目定义底线；3.8 上 SymPy 可用 |
| 符号引擎 | SymPy | 最新 | 纯 Python、无外部服务、可随 exe 内嵌 |
| CLI | argparse (stdlib) | — | 零额外依赖 |
| GUI | PySide6 | 6.6.3.1（3.8 上限） | 6.7+ requires-python≥3.9 |
| 打包 | PyInstaller | ≥6（打 GUI 时） | 5.x 扫描 PySide6 6.6 字节码崩 |
| 测试 | pytest | 最新 | 标准 |
| 快照 | JSON + sha256 | — | 文本可读、可 diff |
| 报告 | Markdown + HTML | — | 人读 + 机读双轨 |

## 四、分层与单向依赖

```
表现层 ──→ 编排层 ──→ 引擎层 ──→ 模型层
                │              │
                │              └→ 数据层（只读）
                └→ 数据层（只读）
```

**铁律**：
1. 引擎层零模型依赖（不 import `src.hws_math_auditor.llm`）
2. 表现层零判定逻辑（只消费引擎 API，不重算任何判定）
3. 数据层零写入（快照/基准/规则包入仓后只读）
4. 模型层零权重分发（只连端点，不随包带权重）

## 六、K 编号口径清单（动了会打挂测试的约定）

| K# | 口径 | 位置 |
|---|---|---|
| K1 | 三级语义：`ok` / `invalid` / `unverifiable`，不可混用 | `src/hws_math_auditor/model/verdict.py` |
| K2 | 首错锚定唯一性：多步同时 invalid 取最小序号 | `src/hws_math_auditor/locator/first_error.py` |
| K3 | 真值库只存 input+expect，不存 observed | `src/hws_math_auditor/benchmark/ground_truth.py` |
| K4 | 误报率 0 优先（干净解答不误报） | `src/hws_math_auditor/benchmark/metrics.py` |
| K5 | 不可符号化步骤标 `unsymbolizable`，不得虚高为 ok | `src/hws_math_auditor/parser/normalizer.py` |
| K6 | 独立重算路径与符号路径实现独立 | `src/hws_math_auditor/recalc/numeric_recalc.py` |
| K7 | 模型开关默认关，审计核心零模型可跑 | `src/hws_math_auditor/config.py` |
| K8 | 数值口径一处定义（plan/02 唯一定义点） | `plan/02-算法与口径说明.md` |
| K9 | 覆盖度分母反射自代码常量，新增类型无用例→生成器报错 | `src/hws_math_auditor/benchmark/generator.py` |
| K10 | 快照 sha256 留档，随仓只存快照与真值台账 | `data/snapshots/` |

## 七、本机环境坑（实测过）

1. **PyInstaller 5.x 打 GUI 崩**：`TypeError: 'Instruction' object is not iterable`——必须 ≥6
2. **PySide6 6.7+ 需 Python ≥3.9**：3.8 上 pip 自动回避，但若手动指定版本会装不上
3. **`py` 启动器会无视 venv**：README 中 venv 段落一律用 `python -m pip`
4. **Windows 子进程输出注入 CRLF**：落盘前 `.replace("\r\n","\n")` 归一
5. **`Path.write_text(newline=)` 是 3.10+**：3.8 上用 `open(..., newline="\n")`
