# plan/05-发布与交付

> 仓库 `HWS-hard-math-solution-auditor`（难题解答步骤级审计与错误定位器）。v1（2026-10-16）。

## 一、交付形态

### 1.1 CLI 形态

- **入口**：`src/hws_math_auditor/__main__.py` + `src/hws_math_auditor/cli.py`
- **命令**：
  - `hws-audit audit --input <解答文件>` — 审计单个解答
  - `hws-audit audit --input <解答文件> --report` — 生成报告
  - `hws-audit benchmark --run` — 运行基准
  - `hws-audit benchmark --metrics` — 输出指标
  - `hws-audit selftest` — 冻结态自检
  - `hws-audit --model` — 启用模型（默认关）

### 1.2 桌面报告形态

- **框架**：PySide6 6.6.3.1（3.8 上限）
- **窗口**：主窗口（审计输入/结果展示）+ 设置页（模型端点配置）
- **报告导出**：Markdown + JSON + HTML

### 1.3 PyInstaller 打包

- **双 exe**：
  - `hws-audit-cli.exe`（console=True，纯 CLI）
  - `hws-audit-gui.exe`（console=False，GUI 窗口）
- **PyInstaller 版本**：≥6（打 GUI 时）
- **spec 分档**：CLI 目标排除 Qt，GUI 目标包含 Qt

## 二、依赖分层（extras）

```toml
[project.optional-dependencies]
dev = [
    "pytest>=7.0",
    "pytest-cov>=4.0",
]
gui = [
    "PySide6>=6.6.3.1,<6.7",
]
build = [
    "PyInstaller>=6",
    "setuptools<81",  # 3.8 兼容
]
```

**铁律**：
- `dev` 不含重件（PySide6/PyInstaller）
- `gui` 仅含 GUI 必需
- `build` 仅含构建工具，不当核心依赖
