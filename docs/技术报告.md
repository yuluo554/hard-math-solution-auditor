仓库 `HWS-hard-math-solution-auditor`。基准日 **2026-10-18**（v0.1.1 修订）。

本报告对应 plan/01 §三 第 5 项"技术报告"（原文写"技术报告 / README"，本文件补齐前者）。

---

## 一、步骤切分与归一化

**输入**：模型输出（可含 `<think>` 思维链）或 LaTeX / 纯文本解答。
**输出**：`Step` 序列（序号 + 原文 + 归一化表达式候选 + 来源行号 + 状态）。

| 状态 | 含义 |
|---|---|
| `normalized` | 成功转为 SymPy 表达式，进入判定路径 |
| `unsymbolizable` | 无法符号化，**不判 ok**，登记原因 |
| `pending` | 尚未处理 |

**覆盖率口径**：分母 = 检出步骤数，分子 = 成功归一化数（`compute_coverage`）。
报告**必须**同时给分母与分子——只报分子会把"切不出来"伪装成"全对"。

**编码**：非 UTF-8 输入一律报错并提示 `--encoding`（不做编码猜测）。

---

## 二、符号验证：三级语义

| verdict | 含义 | 要求 |
|---|---|---|
| `ok` | 相邻步等价且合法 | — |
| `invalid` | 确证错误 | **必须**附最小反例（具体取值） |
| `unverifiable` | 引擎能力外 | 登记能力覆盖度，**不得判 ok** |

**判定不虚高**是本题的核心纪律：把"验证不了"混进"确证错误"会让报告虚高，
混进 `ok` 则会让工具变成橡皮图章。

## 三、首错锚定

`locate_first_error(verdicts, steps)`：

1. 取**最小序号**的 `invalid` 为首错（唯一锚点）；
2. 其余 `invalid` 按"是否直接依赖首错步的输出变量"分为
   `contaminated`（受污染）与 `independent_failures`（独立失效）；
3. 生成解释文本。

**索引口径（v0.1.1 修订）**：内部 API 用 **0 基**（`first_error`，测试依赖），
对外展示一律 **1 基**。v0.1.0 把 0 基直接打印，出现"首错步骤 2 / 解释：首错在第 3 步"
的自相矛盾——已修，并由 `tests/test_report_export.py::test_first_error_is_one_based_for_display` 锁死。

## 四、独立重算

`independent_recalc(assertion, steps)` 用**与符号路径实现独立**的数值路径复算最终断言，
输出三态：一致 / 不一致 / 无法独立重算。

**为什么要独立**：若两条路径共享同一套符号变换，同源错误会互相印证（"假绿"）。
容差与数值口径**一处定义**（`rules` 阈值表），注记文本与算法同源。

## 五、报告导出（v0.1.1 新增实现）

plan/05 §1.2 承诺"报告导出：Markdown + JSON + HTML"。v0.1.0 只把 HTML `setHtml` 到窗口，
**没有导出**。v0.1.1 补 `src/hws_math_auditor/report.py`：

| 项 | 落点 |
|---|---|
| 单一渲染源 | `report_to_dict()`；三种格式都从它取数 |
| 格式 | `render_markdown` / `render_json` / `render_html` |
| CLI | `hws-audit audit --input X --report out --report-formats md,json,html` |
| GUI | 「导出报告（MD + JSON + HTML）」按钮 → `write_all()` |
| 断言 | `tests/test_report_export.py`（12 条：渲染 8 + CLI 2 + GUI 接线 2） |

**HTML 零外链**：无 CDN / 字体 / 图片引用，断网可开（测试扫描 `http://` 与 `https://`）。

## 六、真值纪律与基准

| 纪律 | 实现 |
|---|---|
| 真值库只存 input + expect | 出现 `observed` 字段即守门红 |
| 冻结台账禁手改 | `generator --check` 位级一致；基准消费冻结台账而非当场生成 |
| 覆盖度分母反射自代码常量 | 新增错误类型而无用例 → 生成器直接报错 |
| 预置模型输出快照 | 含生成参数 + sha256，离线可复跑 |

基准套件：六类植入错误（`illegal_algebra` / `divide_by_zero` / `dimension_mismatch` /
`induction_failure` / `boundary_omission` / `symbol_typo`）+ 边界用例，21 条冻结台账。

## 九、已知边界

- 符号化覆盖有限：`unsymbolizable` 步骤如实登记，不判 ok；
- 模型开关默认关；模型只用于抽取兜底/别名归一/复核/行文，**数值结论永远来自确定性规则**；
- 真实竞赛题回归集可选用公开题库，需逐库核对许可（未纳入首期）。
